# KYNO v2 — Roles & Permissions
**نظام الصلاحيات:** Multi-Level RBAC (Role-Based Access Control)

---

## أنواع المستخدمين

KYNO يحتوي على **5 مستويات** من المستخدمين:

```
Level 5 ─── Super Admin          (مدير المنصة)
Level 4 ─── Super Admin Member   (عضو فريق المنصة)
Level 3 ─── Company Admin        (مسؤول الشركة)
Level 2 ─── Company User (HR/Manager) (مستخدم الشركة بصلاحيات مخصصة)
Level 1 ─── Employee             (الموظف — بوابة محدودة)
```

---

## 1. Super Admin (مدير المنصة)

**التعريف:** المالك الكامل للمنصة — مستوى واحد فقط

**الصلاحيات الكاملة:**

```
الشركات:
  ✅ عرض جميع الشركات
  ✅ إنشاء شركة جديدة
  ✅ تعديل بيانات أي شركة
  ✅ حذف شركة
  ✅ تعليق/إيقاف شركة

الاشتراكات:
  ✅ عرض جميع الاشتراكات
  ✅ تفعيل اشتراك
  ✅ تجديد اشتراك
  ✅ تعديل اشتراك
  ✅ حذف اشتراك

المستخدمون:
  ✅ عرض جميع مستخدمي الشركات
  ✅ إنشاء/تعديل/حذف مستخدمي الشركات
  ✅ إعادة تعيين كلمة المرور

فريق Super Admin:
  ✅ إضافة أعضاء جدد لفريق SA
  ✅ تعديل صلاحيات أعضاء الفريق
  ✅ حذف أعضاء الفريق

المنصة:
  ✅ إرسال إعلانات للكل
  ✅ إدارة رقم WhatsApp الدعم
  ✅ عرض إحصائيات المنصة

النظام:
  ✅ عرض System Monitoring
  ✅ عرض Audit Logs الكامل
  ✅ تصدير بيانات أي شركة (Backup)
  ✅ استيراد بيانات شركة
  ✅ تعديل إعدادات المنصة

الصلاحيات الخاصة:
  ✅ row_security = off في بعض RPCs
  ✅ لا حد اشتراك — وصول غير محدود
  ✅ لا rate limiting على تسجيل الدخول
```

---

## 2. Super Admin Member (عضو فريق المنصة)

**التعريف:** أعضاء فريق KYNO بصلاحيات قابلة للتخصيص

**الصلاحيات القابلة للتعيين:**

```
companies_view         — عرض الشركات
companies_create       — إنشاء شركة
companies_edit         — تعديل شركة
companies_delete       — حذف شركة
companies_suspend      — تعليق شركة
subscriptions_renew    — تجديد اشتراك
subscriptions_delete   — حذف اشتراك
users_manage           — إدارة المستخدمين
platform_whatsapp      — تعديل إعداد WhatsApp
platform_announce      — إرسال إعلان
platform_announce_manage — إدارة الإعلانات
team_manage            — إدارة فريق SA
stats_view             — عرض الإحصائيات
```

**القيود:**
```
❌ لا يمكنه تعديل كلمة مرور Super Admin الرئيسي
❌ لا يمكنه حذف أعضاء SA بدون صلاحية team_manage
❌ لا وصول لـ System Monitoring الكامل (حسب الصلاحيات)
```

---

## 3. Company Admin (مسؤول الشركة)

**التعريف:** المسؤول الكامل لشركته — لا يرى شركات أخرى

**الصلاحيات:**

```
الموظفون:
  ✅ عرض / إضافة / تعديل / حذف موظفي الشركة

الحضور:
  ✅ عرض / إضافة / تعديل / حذف / تصدير سجلات الحضور
  ✅ حذف دفعة من السجلات

الأجهزة:
  ✅ عرض / تعديل بصمة أجهزة الموظفين

الرواتب:
  ✅ عرض / إصدار / تعديل / حذف / تصدير كشوف الرواتب
  ✅ عرض / تعديل / حذف الرواتب المدفوعة

الخصومات والسلف:
  ✅ عرض / إضافة / تعديل / حذف / تصدير

الإجازات:
  ✅ عرض / إضافة / تعديل / حذف

الأقسام والوظائف:
  ✅ عرض / إضافة / تعديل / حذف

التقارير:
  ✅ عرض / تصدير

الإشعارات:
  ✅ عرض / قراءة الكل / حذف / تصدير الأرشيف

المستخدمون:
  ✅ عرض / إضافة / تعديل / حذف مستخدمي شركته

الإعدادات:
  ✅ عرض / تعديل إعدادات الشركة

القيود:
  ❌ لا وصول لشركات أخرى
  ❌ لا وصول للوحة Super Admin
  ❌ محدود بـ max_employees من خطة الاشتراك
```

---

## 4. Company User (مستخدم بصلاحيات مخصصة)

**التعريف:** موظف إداري (HR، مدير قسم) بصلاحيات مخصصة من Company Admin

**الصلاحيات:** قابلة للتخصيص — كل إذن يمكن تفعيله أو تعطيله

```
الموحدات والأفعال:
┌─────────────────────┬────────────────────────────────────────────┐
│ Module              │ Actions                                    │
├─────────────────────┼────────────────────────────────────────────┤
│ dashboard           │ view                                       │
│ employees           │ view, add, edit, delete                    │
│ attendance          │ view, add, edit, delete, batch_delete,     │
│                     │ export                                     │
│ device_mgmt         │ view, edit                                 │
│ leaves              │ view, add, edit, delete                    │
│ salaries            │ view, add(issue), edit, delete, export,   │
│                     │ paid_view, paid_edit, paid_delete          │
│ finance             │ view, add, edit, delete, export            │
│ org                 │ view, add, edit, delete                    │
│ reports             │ view, export                               │
│ notifications       │ view, read_all, clear_all, export          │
│ settings            │ view, edit                                 │
│ users_permissions   │ view, add, edit, delete                    │
└─────────────────────┴────────────────────────────────────────────┘

القيود:
  ❌ لا وصول لشركات أخرى (RLS يمنع ذلك)
  ❌ لا وصول للوحة Super Admin
  ❌ محدود بالأذونات المعيّنة من Company Admin
```

## 5. Employee (الموظف)

**التعريف:** الموظف العادي — يدخل عبر بوابة الموظف بالجهاز المسجّل

**الصلاحيات:**

```
بوابة الموظف — الصفحات المتاحة:
  ✅ emp-home    — تسجيل حضور/انصراف، سجل الأسبوع
  ✅ emp-salary  — عرض الراتب الحالي، سجل الرواتب
  ✅ emp-profile — عرض وتعديل محدود للملف الشخصي
  ✅ notifications — إشعاراته المالية والإجازات

الصلاحيات على البيانات:
  ✅ تسجيل حضور/انصراف (عبر fingerprint + RPC anon)
  ✅ عرض بيانات راتبه فقط
  ✅ عرض إجازاته فقط
  ✅ عرض إشعاراته فقط
  ✅ تغيير صورة ملفه الشخصي
  ✅ تعديل رقم هاتفه (مع موافقة مسؤول)

القيود:
  ❌ لا وصول للوحة الإدارة
  ❌ لا يرى بيانات موظفين آخرين
  ❌ لا يرى بيانات مالية شاملة للشركة
  ❌ دخوله مقيّد بالجهاز المسجّل فقط (fingerprint)
  ❌ لا تسجيل دخول إلا من جهاز مرتبط بـ QR
```

## مقارنة المستويات

```
┌─────────────────────┬────┬──────┬───────┬───────┬──────┐
│ الصلاحية            │ SA │ SAM  │  CA   │  CU   │  E   │
├─────────────────────┼────┼──────┼───────┼───────┼──────┤
│ لوحة Super Admin    │ ✅ │  ✅  │  ❌   │  ❌   │  ❌  │
│ إدارة الشركات       │ ✅ │  *   │  ❌   │  ❌   │  ❌  │
│ إدارة الاشتراكات    │ ✅ │  *   │  ❌   │  ❌   │  ❌  │
│ إدارة الموظفين      │ ✅ │  ❌  │  ✅   │  *    │  ❌  │
│ إدارة الحضور        │ ✅ │  ❌  │  ✅   │  *    │  ❌  │
│ تسجيل الحضور        │ ❌ │  ❌  │  ❌   │  ❌   │  ✅  │
│ عرض راتبه           │ ❌ │  ❌  │  ❌   │  ❌   │  ✅  │
│ إصدار الرواتب       │ ✅ │  ❌  │  ✅   │  *    │  ❌  │
│ System Monitoring   │ ✅ │  *   │  ❌   │  ❌   │  ❌  │
│ Audit Logs (كامل)   │ ✅ │  *   │  ❌   │  ❌   │  ❌  │
│ Backup/Export       │ ✅ │  ❌  │  ✅*  │  ❌   │  ❌  │
└─────────────────────┴────┴──────┴───────┴───────┴──────┘

SA  = Super Admin
SAM = Super Admin Member
CA  = Company Admin
CU  = Company User (حسب الصلاحيات المعيّنة)
E   = Employee
*   = حسب الصلاحيات المعيّنة
```

## نظام التحقق التقني

```
1. RLS (Row Level Security):
   - auth_company_id() → company_id في JWT app_metadata
   - auth_is_super_admin() → role = 'super_admin' في JWT
   - يُطبّق على مستوى قاعدة البيانات — لا يمكن تجاوزه

2. Frontend Guards:
   - BasmaPermissions.canAccessPage() — تحقق من الصفحة
   - BasmaPermissionMatrix.hasActionPermission() — تحقق من الفعل
   - data-perm="module.action" — إخفاء/تعطيل عناصر UI

3. RPC Validation:
   - saas_v3_assert_tenant() — تحقق من الـ tenant
   - saas_assert_company_active() — تحقق من صحة الاشتراك
   - saas_assert_employee_limit() — تحقق من حد الموظفين

4. Edge Function Auth:
   - كل طلب يمر بـ auth-session للتحقق من الجلسة
   - JWT يحتوي app_metadata: {saas_user_id, company_id, role}
```
