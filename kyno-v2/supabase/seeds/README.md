# supabase/seeds/

بيانات ابتدائية — تُطبَّق مرة واحدة عند الإعداد الأولي.

---

## الملفات المتوقعة

| الملف | الوصف | يعتمد على |
|-------|-------|-----------|
| `001_plans.sql` | خطط الاشتراك الثلاث | M003 (plans) |
| `002_platform_settings.sql` | إعدادات المنصة الأولية | M015 (platform_settings) |
| `003_super_admin.sql` | حساب SA الأول | M005 (saas_users) |

> هذه Seeds **ليست** migrations — لا تُرقَّم بنفس نظام الـ migrations.

---

## ملاحظة مهمة

كلمة مرور الـ Super Admin **لا تُكتب هنا**.
تُعيَّن عبر Edge Function `auth-set-password` بعد إنشاء الحساب مباشرة.

---

## ترتيب التطبيق

```
1. طبّق جميع Migrations (M001 → M022) أولاً
2. ثم طبّق Seeds بالترتيب: 001 → 002 → 003
```
