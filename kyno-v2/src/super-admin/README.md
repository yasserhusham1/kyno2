# src/super-admin/

واجهة Super Admin — **منفصلة تماماً** عن واجهة الشركات.

---

## المبدأ

Super Admin يرى **كل الشركات** وليس شركة واحدة.
تصميمه مختلف جوهرياً — لا تخلط بين الطبقتين.

---

## المجلدات

| المجلد | الوظيفة |
|--------|---------|
| `companies/` | إنشاء وإدارة الشركات |
| `subscriptions/` | تفعيل وتجديد وإلغاء الاشتراكات |
| `users/` | إدارة مستخدمي SA (super_admin · super_admin_member) |
| `team/` | إدارة فريق SA |
| `stats/` | إحصائيات المنصة الإجمالية |
| `monitoring/` | مراقبة النظام والأخطاء |
| `backup/` | النسخ الاحتياطية |
| `platform/` | الإعلانات والإشعارات العامة |
| `settings/` | إعدادات المنصة العامة |

---

## الأمان

- SA لا يمكنه الوصول لبيانات موظفي شركة محددة
- كل عملية SA تُسجَّل في `audit_logs`
- الصلاحيات تأتي من JWT claim: `role = 'super_admin'`
- جميع RPCs الحساسة تستخدم `SECURITY DEFINER`
